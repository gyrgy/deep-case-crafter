# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose **Report a vulnerability**,
or go to
[github.com/gyrgy/deep-case-crafter/security/advisories/new](https://github.com/gyrgy/deep-case-crafter/security/advisories/new).

Please do not open a public issue for a vulnerability.
